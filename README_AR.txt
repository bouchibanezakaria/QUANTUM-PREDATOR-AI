QUANTUM PREDATOR AI — Telegram Mini App starter
=================================================

الملفات:
- index.html: واجهة عربية RTL تجريبية متجاوبة.
- README_AR.txt: هذا الملف.

مهم:
هذه واجهة أمامية فقط. لا يوجد حالياً مصدر بيانات OTC/Forex ولا محرك إشارات فعلي.
أزرار السوق والإطار الزمني تغيّر الواجهة فقط، وزر التحليل يعرض تنبيهاً بأن البيانات غير مربوطة.
لا تضع Bot Token داخل ملفات HTML أو JavaScript أو مستودع GitHub.

النشر:
1) ارفع index.html إلى المستودع.
2) من GitHub افتح Settings ثم Pages.
3) اختر Deploy from a branch، ثم main و /(root)، واحفظ.
4) بعد ظهور رابط HTTPS، يمكن ربطه بزر Web App في بوت Telegram.
ملاحظة: Telegram Mini Apps تحتاج رابط HTTPS عام. GitHub Pages يوفر استضافة للواجهة الثابتة، لكنه لا يشغّل خادم Python أو بوتاً دائماً.

الخطوة التالية بعد الرفع: تفعيل GitHub Pages ثم إعداد رابط Web App في البوت.
